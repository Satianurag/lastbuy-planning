LastBuy: every unit justified before the final order

LastBuy helps an industrial thermal-camera manufacturer decide its final purchase of a discontinued processor while protecting contracted repair coverage. In a constructed enterprise case, reconciling component coverage, usable stock, duplicate custody and confirmed inbound changes an 18,000-unit, $1.44 million proposal into a 10,000-unit, $800,000 recommendation. The $640,000 difference is modeled, not achieved savings. Four scoped Microsoft Foundry roles quote engineering, service, supply and supplier evidence; deterministic code checks quantities and source freshness. A captured Foundry response summarized 4,800 current units correctly but supplied an older 6,000-unit value in a structured field. Current validation blocks approval and export until the stock record is corrected and analysis rerun. The workflow requires separate engineering, service, finance and procurement approvals of the same plan version; the cloud tenant currently has only a planner user. Export recovery was tested against an ERP simulation. A customer pilot will measure planning time, service coverage and finance-reviewed outcomes.
